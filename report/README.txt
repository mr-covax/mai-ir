Отчёт по лабораторным работам «Информационный поиск»
Книга Тимофей Сергеевич, М8О-409Б-23

Для Overleaf:
1. Создайте ZIP-архив содержимого папки report/: report.tex, src/, styles/ и figures/
   должны находиться в корне архива.
2. Создайте проект через New Project -> Upload Project и загрузите этот архив.
3. Основной файл: report.tex. Компилятор: pdfLaTeX.
4. Рекомендуемая версия TeX Live: 2024 или новее.

Титульные данные редактируются в src/settings.tex.
Каждая лабораторная находится в отдельном src/labNN.tex.
Графики строятся PGFPlots из таблиц в figures.
Внешние программы и shell-escape для сборки не требуются.

В отчёте приведены метрики четырёх систем по 30 запросам,
сравнение raw/VB, сканирование групп частотности и подбор шага прыжков.
Стиль основан на шаблоне курса MAI-IR; лицензия включена в styles.
